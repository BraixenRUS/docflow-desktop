Таблица 1: Модели для компьютерного зрения и обработки изображений
| Название модели | Размер | Потребление RAM/VRAM | Архитектура | Поддержка CPU-only | Сложность дообучения (1-5) | Тип задачи | Вердикт для MVP |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **YOLOv8-Nano** | ~0.5 ГБ (диск)<br>~1 ГБ (RAM) | Низкое (~1 ГБ) | CNN + Transformer | Да (Отлично) | Средняя (3/5) | Детекция объектов<br>(нахождение пятен, шума) | **Рекомендуется для MVP**<br>(Быстро, точно, обучается легко на CPU) |
| **U-Net (Tiny)** | ~0.2 ГБ (диск)<br>~0.5 ГБ (RAM) | Очень низкое | CNN (Encoder-Decoder) | Да (Отлично) | Низкая (2/5) | Сегментация<br>(маскировка дефектов) | Альтернатива для MVP<br>(Меньше ресурсов, но менее гибкая для обучения новых классов) |
| **Stable Diffusion (Inpainting)** | ~4 ГБ (диск)<br>~6-7 ГБ (RAM) | Высокое (требует GPU) | Diffusion GAN | Нет (Только с GPU) | Высокая (4/5) | Восстановление<br>(замена пятна на фон) | **Не рекомендуется для MVP**<br>(Слишком тяжелый для CPU, медленный без видеокарты) |
| **ResNet-18** | ~0.2 ГБ (диск)<br>~0.5 ГБ (RAM) | Низкое | CNN Классификатор | Да (Отлично) | Очень низкая (1/5) | Двоичная классификация<br>(Есть дефект / Нет) | **Не рекомендуется для MVP**<br>(Для простой фильтрации. Не определяет где именно, а только факт наличия) |
| **Tesseract (с модулем детекции шума)** | < 0.1 ГБ | Низкое | HMM/LSTM | Да (Отлично) | Низкая (2/5) | Детекция артефактов на основе текста | **Базовый уровень для MVP**<br>(Работает, но часто ошибается на сложных дефектах) |

Таблица 2: Модели OCR и NLP (для обработки языка)
| Название модели | Размер | Потребление RAM/VRAM | Архитектура | Поддержка CPU-only | Сложность дообучения (1-5) | Тип задачи | Вердикт для MVP |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Llama 3.1 (8B)**<br>(Q4_K_M или Q5_K_M) | ~5-6 ГБ (диск)<br>~9 ГБ (RAM) | Высокое (~9-10 ГБ) | Transformer (LLM) | Да (Средне/Долго) | Средняя (3/5 - LoRA) | OCR + Интерпретация контекста | **Рекомендуется для MVP**<br>(Лучшая точность, понимает сложные термины после обучения) |
| **Qwen2.5 (0.5B)** | ~1 ГБ (диск)<br>~2-3 ГБ (RAM) | Низкое (~3 ГБ) | Transformer (LLM) | Да (Отлично) | Низкая (2/5) | Легкий OCR / Извлечение коротких строк | Альтернатива для MVP<br>(Идеально для слабых ПК, но хуже справляется с длинными документами) |
| **Donut (HuggingFace)** | ~2 ГБ (диск)<br>~3-4 ГБ (RAM) | Среднее | Transformer (DocQA) | Да (Отлично) | Низкая (2/5) | End-to-end OCR без разделения на строки | Хороший эталон для MVP<br>(Быстрее LLM, но сложнее в адаптации под новые шрифты) |
| **Tesseract 5**<br>(Версия с языком RU) | < 100 МБ | Очень низкое (< 500 МБ) | LSTM + N-gram | Да (Отлично) | Не нужно (0/5) | Стандартный OCR | Базовый уровень для MVP<br>(Нужно использовать как контрольную точку "без ИИ") |
| **PaddleOCR (Lightweight)** | ~200 МБ | Низкое (~1 ГБ) | CNN + CRNN | Да (Отлично) | Низкая (2/5) | Специализированный OCR для документов | Альтернатива для MVP<br>(Хорош для таблиц, но требует обучения весов под свои данные) |
