# Разработка десктопного приложения для локального распознавания документов и автоматического определения связей между ними с использованием ИИ

Десктопное приложение для интеллектуальной обработки документов с локальной работой без доступа к интернету. Система распознает содержимое загруженных документов, определяет их тип, извлекает ключевые данные и автоматически выявляет взаимосвязи между документами.

## Цель проекта

Развить существующее приложение для автоматического распознавания и анализа документов с использованием технологий искусственного интеллекта. Система должна извлекать информацию из документов, определять их тип и автоматически находить связи между документами, формируя единую структуру взаимосвязанных данных.

## Функциональность

- Загрузка документов в систему.
- Распознавание текста и ключевых данных.
- Определение типа и назначения документа.
- Поиск связанных документов и автоматическое создание связей между ними.
- Просмотр документов и связанных с ними объектов.
- Поиск и фильтрация документов.

## Технические требования

- Локальная работа приложения без доступа к интернету.
- Поддержка основных форматов документов.
- Сохранение распознанных данных и установленных связей.
- Возможность дальнейшего расширения набора поддерживаемых документов и типов связей.

## Структура репозитория

- `docs/` — проектная документация:
  - Инструкция по работе с сервисом.
  - Описание процесса распознавания документов.
  - Описание логики определения и создания связей между документами.
- `src/` — исходный код приложения.
