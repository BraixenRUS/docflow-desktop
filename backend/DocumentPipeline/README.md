# 📄 Unified Document Processing System (C# / .NET 10)

Единая модульная система для извлечения текста из документов различных форматов. Система автоматически определяет тип файла, использует прямое извлечение текста для цифровых документов и подключает OCR (оптическое распознавание символов) для сканов и изображений.

## 🚀 Поддерживаемые форматы
*   **PDF**: Извлечение текстового слоя напрямую. Для смешанных документов или сканов используется рендеринг страниц в изображения с последующим OCR.
*   **DOCX**: Парсинг структуры документа, включая параграфы и таблицы.
*   **JPEG / PNG**: Распознавание текста с изображений с помощью OCR.

## 🏗️ Архитектура и Модульность

Проект спроектирован с учетом принципов **SOLID** и использует паттерны **«Стратегия»** и **«Фабрика»**. Это позволяет легко расширять систему без изменения уже работающего кода.

*   `IDocumentProcessor` — единый интерфейс для всех форматов. Каждый формат реализуется в виде отдельного класса-стратегии.
*   `IOcrEngine` — абстракция OCR-движка. Позволяет использовать Tesseract (по умолчанию) или PaddleOCR с GPU-ускорением, не меняя код обработки форматов.
*   `ProcessorFactory` — фабрика, которая автоматически выбирает нужный обработчик на основе расширения файла.
*   `DocumentExtractionPipeline` — единая точка входа (Facade), объединяющая работу фабрики и OCR.
