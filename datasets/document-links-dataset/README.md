# Dataset: Нормативные акты РФ с формальными связями по номерам

## Источник
Документы соответствуют реальным нормативным правовым актам РФ, размещённым на портале Минюста России **pravo.minjust.ru**, а также на официальном портале опубликования **publication.pravo.gov.ru**. Текстовые фрагменты, приведённые в `documents/`, достаточны для разметки ключевых полей и проверки связей по номерам.

## Состав
- **20 документов** (D01–D20): федеральные законы, постановления и распоряжения Правительства, указы Президента, приказы министерств.
- Тексты сохранены в `documents/Dxx.txt`.
- Разметка ключевых полей — в `annotations/Dxx.json`.
- Эталонная карта связей — `ground_truth_links.csv`.

## Формат CSV
`source_id, target_id, target_number, link_type, evidence`

- `target_id` заполняется, если целевой документ входит в набор D01–D20. Если документ внешний — поле пустое, ориентир — `target_number`.

## Лицензия
Тексты нормативных правовых актов являются официальными документами и не являются объектами авторского права (ст. 1259 ГК РФ).
